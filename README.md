# Finora Accounting & Finance SQL Database Project

This project is a **Finance and Accounting Database Management System** developed using **MySQL and SQL**. The project simulates a real-world accounting and financial services company, **Finora Accounting**, and demonstrates how relational databases can be used to manage business operations and financial data.

The database contains four main entities: **Departments, Employees, Clients, and Projects**. It stores employee details, job roles, salaries, departments, client information, industries, project details, project budgets, and project timelines.

The project demonstrates important SQL concepts including **Primary Keys, Foreign Keys, Constraints, INNER JOINs, WHERE, ORDER BY, GROUP BY, HAVING, DISTINCT, Aggregate Functions, Subqueries, CASE statements, IF() functions, Views, UPDATE, DELETE, and LIMIT**.

Several analytical queries are included to calculate **average, minimum, maximum, and total salaries**, department-wise employee statistics, client-wise project budgets, and overall project budgets. A database view is also created to combine employee and department information for easier reporting.

This project is designed as a practical **SQL portfolio project** to demonstrate skills in database design, relational data management, SQL querying, financial data analysis, and business reporting.
